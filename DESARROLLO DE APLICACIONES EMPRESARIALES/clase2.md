# Rest, Graphql y GRPC

## limitacion de rest

suele ser el estandar pero tiene problemas con sistemas complejos como

- over fetching: trae mas info de la que el cliente necesita
- imder-fetching: se necesitan muchas fuentes(muchos request) para obtener toda la informacion
-

## GraphQL

el cliente declara que datos necesita se hace por medio de querys datos relacionados

# GRPC

basado en **_protocol buffers_** es apropiado para comunicacion interna entre microservicios es
enfocado en la velocidad o desempeño pero es bastante estricto y protocolario
